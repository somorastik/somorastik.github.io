# Rastislav Somora — Interactive Creative Portfolio

Responsive single-page website built with HTML, CSS and JavaScript. No build tools or packages are needed.

## Run
Open `index.html` in a modern browser. Internet access is used for illustrative Unsplash images and YouTube links.

## Interactive features
- Project filters for QA, hardware and audio
- Image gallery lightbox with previous/next buttons and keyboard arrow keys
- Escape key and backdrop click close dialogs
- YouTube search dialog for the featured video
- Active-section navigation
- Responsive desktop/mobile layout

## Personalize before publishing
- Replace `YOUR.EMAIL@example.com` with your real email.
- Replace LinkedIn and GitHub links with your actual profiles.
- YouTube links currently open relevant searches because no personal video URLs were provided. Replace them with actual video URLs when available.
- Illustrative images are not claimed as your work. Replace them with your own project photos, screenshots and audio imagery.
- Add verified outcomes to the SHD AG and Fiserv case notes. No metrics have been invented.
- Keep employer-confidential information out of the public site.
- The independent electronics project section is presented as a concept until you add evidence of a completed build.

## Hosting
Upload `index.html` to GitHub Pages, Netlify or any static web host.


## Hacker theme update

The visual system takes cues from the official [Hacker GitHub Pages theme](https://github.com/pages-themes/hacker): dark graphite surfaces, terminal-style monospace typography, green signal accents and cyan/Morpho-blue highlights. Project filters, gallery lightbox, keyboard controls, video modal and responsive layout remain in `index.html`.

`_config.yml` and `assets/css/style.scss` are included for a GitHub Pages/Jekyll setup using `pages-themes/hacker@v0.2.0`. The standalone HTML file remains directly previewable. Test the Jekyll build before replacing a live site.
