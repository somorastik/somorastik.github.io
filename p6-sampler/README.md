# Six-Pad Sampler

A clean-room, playable study of the Roland P-6 granular sampler workflow, built for the browser from the owner's manual and the P-6 backup file format: six pads, a granular engine, effects and patterns. It can load your own `P6_SAMPLE_PATTERN` backup.

**Play it:** https://somorastik.github.io/p6-sampler/

Roland and P-6 are trademarks of Roland Corporation. This study is unofficial, is not affiliated with Roland, and uses none of Roland's code, artwork or sounds. Factory samples appear only if you load your own backup.

This branch holds the page itself (`index.html`, one self-contained file). The site's `main` branch copies it into `p6-sampler/` whenever this branch changes.
