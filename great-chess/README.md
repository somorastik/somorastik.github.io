# Great Chess

Tamerlane's chess (Timur's "great chess") in the browser: the 11 × 10 board with citadels, played against the computer in 2D or 3D, with a tutorial and the full rules.

**Play it:** https://somorastik.github.io/great-chess/

This branch holds the page itself (`index.html`, one self-contained file). The site's `main` branch copies it into `great-chess/` whenever this branch changes.
